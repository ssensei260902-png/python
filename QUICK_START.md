## 🤖 Automation Scripts You Can Use TODAY

### 1. Organize Downloads
```python
from automation_scripts import organize_downloads
organize_downloads()
```
**Result**: Downloads sorted into Images/, Documents/, Videos/, etc.

### 2. Create Backups
```python
from automation_scripts import create_backup
create_backup('/path/to/important/folder', '/path/to/backups')
```
**Result**: Timestamped backup with automatic rotation

### 3. Find Duplicates
```python
from automation_scripts import find_and_remove_duplicates
find_and_remove_duplicates('/path/to/folder', remove=False)  # Just report
find_and_remove_duplicates('/path/to/folder', remove=True)   # Delete them
```
**Result**: Find and remove duplicate files, free up space

### 4. Batch Rename
```python
from automation_scripts import batch_rename_files
batch_rename_files('/path/to/photos', 'IMG', 'Photo')
```
**Result**: IMG_001.jpg → Photo_001.jpg (all files renamed instantly)

### 5. Monitor Directory
```python
from automation_scripts import monitor_directory
monitor_directory('/path/to/watch')
```
**Result**: Real-time alerts when files change
