## 🚀 Getting Started

### Option 1: Open Directly in Browser (Simplest!)

1. **Open the platform**: Double-click `index.html` to open in your web browser
2. **Wait for Python to load**: The first time you open it, Pyodide (Python in browser) will download (may take 10-30 seconds)
3. **Start learning**: Navigate through modules using the sidebar
4. **Run code**: Click "▶ Run Code" buttons to execute examples

### Option 2: Using a Local Web Server (Recommended)

For better performance and features, run a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Or using Python 2
python -m SimpleHTTPServer 8000
```

Then open: `http://localhost:8000` in your browser

### Option 3: Using VS Code Live Server

1. Install "Live Server" extension in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"

## 🐛 Troubleshooting

### Python Not Loading
- **Issue**: "Python engine is loading..."
- **Solution**: Wait 30-60 seconds for Pyodide to download on first load
- **Check**: Ensure you have an internet connection

### Code Not Running
- **Issue**: Nothing happens when clicking "Run Code"
- **Solution**: Check browser console for errors (F12)
- **Try**: Refresh the page and wait for Pyodide to load

### Syntax Errors
- **Issue**: "SyntaxError" in output
- **Solution**: Check your code for typos, missing colons, incorrect indentation
- **Tip**: Python is sensitive to indentation - use spaces, not tabs

### Import Errors
- **Issue**: "ModuleNotFoundError"
- **Solution**: Some libraries may not be available in Pyodide
- **Note**: Standard library and most common packages work fine
